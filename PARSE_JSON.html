Nested Data Model

👤 profile

Who is the prospect?

identity, contact, company, role

🎯 qualification

Is this a qualified opportunity?

need, budget, timeline, authority, fit, score

💬 message

What did the prospect communicate?

intent, pain_points, requirements, sentiment

⚙️ metadata

How should the record be managed?

source, status, timestamps, extraction

Expected Nested JSON Structure

profile
identity → name, first_name, last_name
contact → email, mobile
company → name, website, industry, size
role → job_title, department
qualification
need → requirement, use_case
budget → amount, currency, stated
timeline → value, urgency
authority → decision_maker, role
fit → score, rationale
qualification_status
message
intent → primary, buying_signal
pain_points → array
requirements → array
questions → array
sentiment
source_message
metadata
lead_source, captured_at, extraction_model, extraction_version
